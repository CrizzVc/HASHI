How to create your own extension?

Steps to register and execute an extension in HASHI

1

Create your folder

Copy this folder to %APPDATA%/hashi/extensions/your-extension or develop inside the extensions directory.

2

Edit manifest.json

Configure id, name, entryUrl (e.g. http://localhost:3001) and set sidebar: true.

3

Start backend

In the backend/ folder, run npm install and then npm start to launch the Express server.

4

Open in HASHI

Open the Extensions modal in HASHI, click Reload, and your extension will be ready to use.
