¿Cómo crear tu propia extensión?

Pasos para registrar y ejecutar una extensión en HASHI

1

Crea tu carpeta

Copia esta carpeta en %APPDATA%/hashi/extensions/tu-extension o utilízala desde el directorio de extensiones.

2

Edita el manifest.json

Configura el id, name, entryUrl (por ejemplo http://localhost:3001) y activa sidebar: true.

3

Inicia el backend

En la carpeta backend/, ejecuta npm install y luego npm start para iniciar el servidor Express.

4

Ábrela en HASHI

Abre el modal de Extensiones en HASHI, pulsa Recargar y verás tu extensión lista para usarse.
